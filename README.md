# Four In A Row

Four In A Row is a C# project developed as part of an academic course.  
The project implements the classic "Four in a Row" game, including a dynamic board, two-player gameplay, and an option to play against the computer.

The project was built using Object-Oriented Programming principles and focuses on clean game logic, board management, and user interaction.

---

## Features

- Classic Four in a Row gameplay
- Two-player mode
- Player vs Computer mode
- Dynamic game board
- Win detection
- Draw detection
- Turn-based gameplay
- Input validation
- Object-Oriented design

---

## Technologies

- C#
- .NET
- Visual Studio

## Project Structure

The project is organized as a Visual Studio solution and includes the game logic and UI components required to run the application.

## Installation and Running

To run this project:

1. Clone the repository:

~~~bash
git clone https://github.com/git-maris/Four-In-A-Row.git
~~~

2. Open the project folder.

3. Open the `.sln` file using Visual Studio.

4. In Visual Studio, set the UI project as the Startup Project:

   - Right-click the UI project
   - Select **Set as Startup Project**

5. Run the project.

---

## Usage

After running the application, choose the game mode and start playing.

Players take turns placing pieces on the board.  
The goal is to connect four pieces in a row — horizontally, vertically, or diagonally.

The game ends when one player wins or when the board is full and the game results in a draw.
